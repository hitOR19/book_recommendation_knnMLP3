Book Recommendation System using K-Nearest Neighbors


Overview:


This project implements a book recommendation system using the K-Nearest Neighbors (KNN) algorithm. The goal is to recommend books that are similar to a given book based on user rating patterns.
The system uses collaborative filtering, where recommendations are generated by identifying books with similar user interactions.
________________________________________
Motivation:


Recommender systems are widely used in platforms like e-commerce, streaming services, and online libraries. This project was chosen to understand how similarity-based recommendation systems work using real-world data.
________________________________________
Dataset:


The dataset used is the Book-Crossings dataset, which contains:
•	Over 1 million ratings
•	Around 270,000 books
•	Approximately 90,000 users
________________________________________
Approach:


1. Data Cleaning:
•	Removed users with fewer than 200 ratings
•	Removed books with fewer than 100 ratings
•	Ensured meaningful and reliable recommendations
2. Data Transformation:
•	Merged book and rating datasets
•	Created a pivot table (book vs user matrix)
•	Filled missing values with 0
3. Model:
•	Used K-Nearest Neighbors from scikit-learn
•	Distance metric: Cosine similarity
•	Algorithm: Brute-force search
4. Recommendation Logic:
•	For a given book, find nearest neighbors
•	Return top 5 similar books with similarity scores
________________________________________
Challenges Faced:


1. Large Dataset Handling
The dataset was large and sparse, which made processing slower.
Solution:
Converted the dataset into a sparse matrix using csr_matrix to improve efficiency.
________________________________________
2. Data Filtering:
Initially, recommendations were not meaningful due to noisy data.
Solution:
Filtered users and books based on minimum rating thresholds.
________________________________________
3. Indexing Issues:
Faced issues while mapping book titles to matrix indices.
Solution:
Used .get_loc() to correctly retrieve index positions.
________________________________________
Results:


The model successfully recommends similar books based on user preferences. The output includes:
•	Input book title
•	List of recommended books
•	Distance (similarity measure)
